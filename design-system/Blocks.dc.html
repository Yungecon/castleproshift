Components 08

Editorial blocks

Four blocks carry everything the memo register has to say. All four are built from the same two ingredients — a bold utility label and a run of ink-soft prose — and differ only in how they are ranged.

Definition list

The workhorse. A 96px tag column against a flexible definition, one hard black rule at the top edge, 14% dividers between rows, 12 of padding above and below each. The tag takes 3px of padding-top so its cap height lines up with the first line of prose beside it.

Confirmed A reading the documents already agree on. Safe to build against.
Translated An old treatment restated in current terms. The original is retired, not deprecated — do not reintroduce it.
Open A live question with the options stated. Anything marked open needs a decision before it spreads.
Two column split
One. Ranged label

Equal halves, 48 gutter, no rule between them. A numbered label sits above each run of prose at 10 of clearance, and stacked pairs inside one column take 28 to 32 between them.

Two. Ordinal words

Points are counted in words, not digits, and the count belongs to the label rather than a marker in the gutter. Digits in this system mean prices, folios and measurements.

A specimen block that shows a scale by setting it rather than tabulating it. A 52px numeric column at 10px mute, a 16 gap, then the sample at its real values. Use it for tracking, weight or value ramps; never for sizes, which need a table.
The aside

Every rule above is a reading of documents that already shipped. Where this system guesses, it says so in clay italic and marks the item open.

Clay-deep italic, set inline inside a paragraph — never pulled out into a box, a band or a quote. One per page, and only where the page changes its own footing.
