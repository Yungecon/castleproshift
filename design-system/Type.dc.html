Foundations 04

Type

Montserrat throughout, in two weights and two slopes. The system gets its range from tracking, case and value rather than from a second family, which is why a 44-page list and a memo set can look like one house without sharing a single size.

Four cuts, no more
Regular 400 Body, list titles at scale, the cuvée slot, everything unmarked.
Bold 700 Memo headings, every utility label, the producer inside an entry.
Regular italic A structural slot in black; a voice in clay deep. Never both on one page.
Bold italic Loaded but unused. No page has yet needed it; treat a first use as a decision.
The tracking ladder

Tracking, not size, is what tells the reader how far up the page hierarchy a line of small caps sits. Four rungs are in service. Each one is claimed by exactly one role, so a new small-caps element joins an existing rung rather than inventing a value between two.

.42em Masthead Cover only. One instance per document.
.30em List head Section labels and the list-register page eyebrow. Regular, not bold.
.18em Memo eyebrow Sits above a memo heading. Tighter and bolder than its list twin.
.14em Utility label Black, never clay. Sub-labels and the tag column of a definition list.
